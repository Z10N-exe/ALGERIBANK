# Bank Services Comparison Platform

This project is a **web application** designed to compare the services and fees of banking providers operating in Algeria.  
The platform aims to provide users with all the necessary information for opening, closing, and managing a bank account, as well as comparing offers between different banks.

## 📌 Features 👨‍💻 STOVEZION IS GOD



* **Public website (Front-End)**

  * Homepage with logo, menu, image carousel, content area, and footer.
  * Bank cards displaying basic details: name, logo, headquarters address, phone, and fax.
  * “More details” section showing services and tariffs by category in structured tables.
  * Sorting banks alphabetically or by ascending service costs.
  * Filtering banks based on service prices between two selected values.
  * Comparison page to select two banks and display a comparison table of fees (green for the lowest price, red for the highest).
  * “About us” page describing the platform’s objectives.
  * Embedded map displaying the geographic distribution of each bank’s agencies across the country.
* **Administration (Back-End)**

  * Secure login page with encrypted credentials.
  * Admin dashboard to manage (add, delete, update) banks, services, tariffs, and website sections.
  * All information is dynamic and can be updated at any time.
* **Architecture \& Implementation**

  * MVC (Model-View-Controller) pattern ensuring separation of data, business logic, and presentation.
  * Database management with an SQL-based DBMS.
  * Web technologies: **HTML, CSS, JavaScript** on the client side.
  * Responsive design for compatibility with PC, laptop, tablet, and smartphone.
* **Security**

  * Basic web security principles applied to protect user data and administrative access.

## 🎯 Objectives

The main goal of this project is to deliver an ergonomic, reliable, and secure platform that allows Algerian citizens to:

* Access and compare detailed banking offers.
* Make informed decisions based on pricing and services.
* Empower administrators to easily update banking information in real time.
